# Makefile

Проект использует `Makefile` для запуска основных задач разработки.

## Доступные команды

| Команда | Описание |
|---------|----------|
| `make deps` | Устанавливает `goose` в локальную директорию `./bin`. |
| `make lint-deps` | Устанавливает `golangci-lint` и `mockery` в локальную директорию `./bin`. |
| `make lint` | Запускает проверку кода с помощью `golangci-lint`. |
| `make test` | Запускает все обычные Go-тесты. |
| `make test-cover` | Запускает тесты и формирует отчёт о покрытии кода. |
| `make test-integration` | Применяет миграции к тестовой БД и запускает интеграционные тесты с покрытием. |
| `make migrate-up` | Применяет все новые миграции к локальной базе данных. |
| `make mock` | Генерирует моки с помощью `mockery`. |
| `make clean` | Удаляет локальную директорию `./bin`. |
| `make build` | Собирает Docker-образы проекта с передачей версии и хэша коммита. |
| `make up` | Собирает и запускает проект в обычном режиме. |
| `make down` | Останавливает и удаляет контейнеры обычного режима. |
| `make debug` | Собирает и запускает проект в режиме отладки (Delve). |

## Тесты

### Обычные тесты

Запустить все обычные тесты:

```bash
make test
```
### Покрытие

Для получения отчёта о покрытии:

```bash
make test-cover
```
Команда выводит покрытие по функциям и открывает HTML-отчёт.

### Интеграционные тесты

Интеграционные тесты используют отдельную тестовую PostgreSQL-базу.

Запуск:

```bash
make test-integration
```

Перед запуском тестов команда применяет все миграции к тестовой базе данных, после чего запускает тесты с build tag integration.

Интеграционные тесты также можно запускать непосредственно из IDE с использованием build tag integration.

## Режимы запуска

### Обычный режим

```bash
make up
```

Запускает приложение, PostgreSQL, Redis, миграции и остальные сервисы.

Остановить:

```bash
make down
```

---

### Режим отладки

```bash
make debug
```

Запускает проект с использованием `docker-compose.debug.yml`. Сервис API стартует под управлением Delve и доступен для подключения удалённого отладчика.

По умолчанию Delve слушает порт:

```text
40000
```

Остановить:

```bash
make debug-down
```

## Версия приложения

Во время сборки Docker автоматически передаются:

- `APP_VERSION` — результат `git describe --tags --always`
- `APP_COMMIT_HASH` — короткий SHA текущего коммита

Эти значения доступны приложению через `ldflags`.

## Генерация моков

Для генерации моков используется mockery:

```bash
make mock
```
